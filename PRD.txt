                           1. EXECUTIVE SUMMARY
================================================================================

Circula-Request is an enterprise-grade workflow management platform designed 
to streamline internal operations, performance management, and organizational 
communication for mid-to-large enterprises.

The platform addresses three critical business needs:
  • Structured approval workflows for organizational requests
  • Employee performance tracking and KPI management
  • Centralized company-wide communication (circulars)

Key Differentiator: AI-powered performance insights and recommendations that 
transform the platform from a passive tracking tool into an active coaching 
and development system.

================================================================================
                        11. SECURITY REQUIREMENTS
================================================================================

AUTHENTICATION
--------------
• JWT-based stateless authentication
• Access tokens: 15-minute expiry, stored in memory
• Refresh tokens: 7-day expiry, stored in httpOnly cookie
• Token refresh happens automatically before expiry
• Logout invalidates refresh token server-side

AUTHORIZATION
-------------
• Role-based access control (RBAC)
• Roles: Staff, Manager, HR Admin, HOD, CFO, COO, MD
• Resource-level permissions checked per request
• Users can only access their own data unless authorized

DATA PROTECTION
---------------
• Passwords hashed with bcrypt (10 salt rounds)
• Sensitive data encrypted at rest
• All API communication over HTTPS
• SQL injection prevention via parameterized queries
• XSS prevention via input sanitization

SESSION MANAGEMENT
------------------
• Concurrent session support with limits
• Session revocation on password change
• Activity timeout after 30 minutes of inactivity

AUDIT LOGGING
-------------
• All authentication attempts logged
• All data modifications logged with user ID
• Approval actions logged with timestamps
• Log retention: 90 days minimum
